# Sergio Villa — personal website

A responsive, Frutiger Aero inspired resume website. Plain HTML, CSS, and JavaScript; no installation, build, API keys, or backend required.

## Preview

Open `index.html` in a browser. Internet access is optional: Google Fonts has local system-font fallbacks. All artwork and the resume download are local assets.

## Publish on GitHub Pages

1. Upload `index.html`, `styles.css`, `script.js`, `.nojekyll`, and the entire `assets` directory to a GitHub repository (or push this folder).
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select your branch (usually `main`) and **/ (root)**, and save.
4. GitHub will display your published URL after deployment.

Relative asset links support both `username.github.io` and `username.github.io/repository-name/` hosting.

## Content

Professional summary, job descriptions, dates, education, skills, and contact information are transcribed from the supplied resume. Macy’s has no employment dates in the source, so the site uses “Seasonal” without inventing dates. Introductory and closing copy is editorial; no additional personal history or achievements were invented.

The original, unchanged resume is in `assets/Sergio_Villa_Resume.docx`. Update the page and replace that file together when your resume changes. The supplied replacement images are used in three places: `asadal_stock_209.jpg` as the city-and-meadow hero background (`assets/aero-city.jpg`), `perfect_hue_189.jpg` inside the glass hero orb (`assets/aero-architecture.jpg`), and `asadal_stock_58.jpg` as the aquatic contact background (`assets/aero-water.jpg`). The original inspiration image has been removed. The favicon is original SVG artwork included in this project.

The page intentionally includes the email address and phone number from the resume, plus the downloadable original. Review those details before making the repository public.
